    How to use

    • 56 red pins are already on the front row (children sitting on the floor). Hover says “Front row 1” … “Front row 56”.
    • Click a pin and type the real name. The coloured pin then disappears; hover that spot to see the name.
    • Use “Show named pins” if you need the green dots back to edit a name.
    • Click empty ground to add extra pins for other rows.
    • Hover a pin to see the name.
    • Click an existing pin to edit or remove it.
    • Export saves a JSON file you can keep or send to someone else.
    • Keep identify.html and school_photo.jpg in the same folder.
