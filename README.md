# Forest Fields Grammar School, April 1970

Interactive naming page for the school panorama.

Live page (after you enable GitHub Pages):

`https://YOUR-GITHUB-USERNAME.github.io/YOUR-REPO-NAME/`

## Files to upload

| File | Purpose |
|---|---|
| `index.html` | The naming page |
| `school_photo.jpg` | Original panorama |
| `.nojekyll` | Tells GitHub to serve the files as-is |

You do **not** need the README on the live site, but it can stay in the repo.

## Create the GitHub page (about 5 minutes)

1. Sign in at [github.com](https://github.com) (create a free account if needed).
2. Click **New repository**.
3. Repository name: anything short, e.g. `forest-fields-1970`.
4. Set it to **Public** (required for free GitHub Pages).
5. Do **not** tick “Add a README” if you are about to upload these files; or if you do, just replace them.
6. Click **Create repository**.
7. On the repo page click **Add file → Upload files**.
8. Drop in:
   - `index.html`
   - `school_photo.jpg`
   - `.nojekyll`
9. Click **Commit changes**.
10. Open **Settings → Pages** (left sidebar).
11. Under **Build and deployment**:
    - Source: **Deploy from a branch**
    - Branch: **main**
    - Folder: **/ (root)**
12. Click **Save**.
13. Wait one or two minutes, then refresh that Pages settings screen. GitHub will show the URL:

`https://YOUR-GITHUB-USERNAME.github.io/YOUR-REPO-NAME/`

That is the link to send people.

## What visitors can and cannot do

- Anyone with the link can open the photo, hover pins, and add names **on their own device**.
- Names are stored in **their browser only**. They are not saved on GitHub.
- To keep a master list: use **Export names**, download `forest-fields-1970-names.json`, and keep that file.
- To load a master list onto another computer: **Import names** and choose that JSON file.

If several people name pupils, collect their exported JSON files and import them one at a time on your copy (later names overwrite the same pin if both edited it).

## Updating the page later

Upload a new `index.html` or `school_photo.jpg` over the old ones in the same repo (**Add file → Upload files**). Pages updates in a minute or two.

## Privacy

A public GitHub Pages site can be opened by anyone who has the link. Do not put surnames on the page if you are not happy for the link to circulate.
